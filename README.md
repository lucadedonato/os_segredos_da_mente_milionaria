<h3 align="center">Arquivo de Riqueza nº 1</h3>

```bash
# Arquivo de Riqueza nº 1

  Pessoas de mentalidade pobre se colocam no papel de vítimas.

  Geralmente a culpa sempre é: Da família, namorada, amigos, economia, governo...
  Costumam culpar sempre os outros por sua situação, mas nunca a si mesmas.

  Essas pessoas acreditam que não têm controle sobre o que acontece na vida delas, e esperam que as coisas mudem sozinhas.

  Para criar riqueza, é necessário adotar uma mentalidade oposta.
  Isso significa:
  ---> Aceitar que você é o principal responsável por sua vida financeira.
  ---> Parar de culpar os outros.
  ---> Tomar ações para atingir suas metas.

  Os ricos se veem como criadores de sua realidade.
  Eles acreditam que suas decisões, ações e atitudes moldam o futuro.
  Eles buscam soluções, enfrentam desafios e assumem responsabilidade por seus resultados.

# Arquivo de Riqueza
  ---> Os pobres acreditam: A vida acontece comigo.
  ---> Os ricos acreditam: Eu crio minha própria vida.
```


<h3 align="center">Arquivo de Riqueza nº 2</h3>

```bash
# Arquivo de Riqueza nº 2

  Pessoas com mentalidade pobre se preocupam em economizar.
  Elas focam em como guardar dinheiro, e não em como fazê-lo crescer.
  Resultado? A pessoa rica aumenta suas chances de ganhar, enquanto a pessoa pobre nunca sai do lugar.

  Problema: Dinheiro parado nunca gera riqueza.
  Ricos enxergam dinheiro parado como perda, pois deixará de trabalhar para eles.
  Dinheiro é uma ferramenta para gerar mais dinheiro.

  ---> Renda Fixa = Perda Fixa

  Em vez de pensar: Quanto posso guardar este mês?
  Passe a pensar: Como posso multiplicar o que tenho?

  A chave é: Criar novas fontes de renda.
  Pense em maneiras de fazer o dinheiro crescer enquanto você dorme.

  O primeiro passo é sempre o mais difícil.

# Arquivo de Riqueza
---> Os pobres acreditam: Preciso proteger meu dinheiro.
---> Os ricos acreditam: Preciso multiplicar o que tenho.
```


<h3 align="center">Arquivo de Riqueza nº 3</h3>

```bash
# Arquivo de Riqueza nº 3

  Pessoas ricas assumem o compromisso de serem ricas.
  Pessoas pobres apenas desejam riqueza.

  Pessoas de mentalidade pobre têm crenças limitantes que as impedem de alcançar riqueza, como:
  ---> "Eu posso perder tudo"
  ---> "Dá muito trabalho"
  ---> "Meus amigos/parentes vão dizer: Quem você pensa que é?"

  Comprometer-se significa: Dedicar-se incondicionalmente.
  Palavra-Chave: Incondicionalmente!

  É preciso estar disposto a fazer o que for necessário.

  Você está disposto a abrir mão e sacrificar seu tempo de lazer para alcançar a riqueza? 
  As pessoas ricas estão.

  "Serei rico ou morrerei tentando."

# Arquivo de Riqueza
---> Os pobres acreditam: Querer é o bastante.
---> Os ricos acreditam: Vou me dedicar incondicionalmente.
```

```bash
  ---> Oferta
  ---> Demanda
  ---> Qualidade
  ---> Quantidade

# Arquivo de Riqueza
---> Os pobres acreditam: Pensar grande é um risco.
---> Os ricos acreditam: Pensar grande é um plano.
```

<h3 align="center">Arquivo de Riqueza nº 13</h3>

```bash
# Arquivo de Riqueza nº 13

	Os ricos focam no seu patrimônio líquido.
	Os pobres focam no seu rendimento mensal.

	O que é patrimônio líquido?
	---> Patrimônio líquido = Quanto você custa

	É o valor total do que você tem (dinheiro, imóveis, investimentos) menos as dívidas.

	Rendimentos: São todas as formas de dinheiro que entram para você.
		Renda ativa: Dinheiro que você recebe por trabalhar. Se você parar de trabalhar, para de ganhar.
		Renda passiva: Dinheiro que entra de forma automática, mesmo se você não estiver trabalhando.

	Se você quiser enriquecer de verdade, precisa focar em construir patrimônio — não apenas em aumentar seu salário!
	Existem 4 pilares para isso:

	1. Simplifique
		Seu estilo de vida (Gaste menos do que ganha — é impossível enriquecer se você não resolver esse ponto!).
		Controle seus gastos.

	2. Aumente sua renda
		Busque formas de ganhar mais. Isso dá mais "combustível" para investir depois.

	3. Guarde
		Cuidado! Guardar não significa deixar o dinheiro parado.
		Significa direcionar para os locais corretos (Onde rende mais).

	4. Invista
		Faça seu dinheiro trabalhar para você de forma estratégica.
		Investir bem vai gerar mais renda, criando um ciclo infinito!

	Construir patrimônio = Construir fontes de rendas passivas

# Arquivo de Riqueza
	---> Os pobres acreditam: Como eu aumento meu salário?
	---> Os ricos acreditam: Como fazer meu dinheiro trabalhar para mim?
```

```bash
# Arquivo de Riqueza nº 14

	Pobres cuidam mal do dinheiro ou evitam lidar com ele.

	Não importa quanto dinheiro você ganha — o importante é o que você faz com ele.

	Muita gente acha que só deve cuidar do dinheiro depois de ficar rica, mas essa ideia só impede o próprio crescimento.
	Se você não consegue gerenciar pequenas quantias, jamais irá administrar grandes fortunas.

	O segredo está em criar o hábito de direcionar seu dinheiro para os lugares corretos.
	Cuidar bem do seu dinheiro envolve:
		---> Saber exatamente quanto você ganha e quanto você gasta.
		---> Despesas do mês: No máximo 50% do que você ganha, independentemente de quanto — ou seja, mesmo sendo rico.
		---> No mínimo 20% do que você ganha deve ser usado para investir e gerar renda passiva.
		---> Pegue até 10% do que você ganha e use esse valor só para se divertir com algo que te faça se sentir especial e recompensado.

	Ou você controla o seu dinheiro, ou ele vai controlar você.

# Arquivo de Riqueza
	---> Os pobres acreditam: Quando eu tiver muito dinheiro, vou começar a administrar.
	---> Os ricos acreditam: Quando eu começar a administrar minhas finanças, terei muito dinheiro.
```


<h3 align="center">Arquivo de Riqueza nº 15</h3>

```bash
# Arquivo de Riqueza nº 15

    A pessoa rica faz o dinheiro trabalhar para ela — ou seja, cria fontes de renda passiva.
    Existem dois tipos de renda passiva:
    ---> 1. Investimentos em que outras pessoas participam – como ações, fundos imobiliários, etc.
    ---> 2. Ter os bens próprios – como aluguel de imóveis, produtos, licenças, serviços, etc.

    Pessoas de mentalidade pobre trabalham pelo dinheiro.
    Vivem nesse ciclo: Trabalham → Recebem → Gastam → Voltam a trabalhar...

    Para as pessoas ricas, trabalhar duro é uma situação temporária.
    O segredo é: sempre pensar ao longo prazo.

    Exemplo:
    ---> Você prefere ganhar 1 milhão de reais por dia ou ganhar 10 centavos que se multiplicam todos os dias?
    ---> Em um mês, 1 milhão por dia totaliza 30 milhões, enquanto os 10 centavos que se multiplicaram passaram de 53 milhões!

    Os pobres dão a desculpa: Como posso pensar no amanhã se mal consigo sobreviver agora?
    O problema em dizer isso é que o amanhã se tornará o hoje.

    É uma questão de escolhas: Quem pensa pequeno opta pelo agora.
    Gastar o que você não tem mostra que está tentando compensar algo que falta na sua vida.

# Arquivo de Riqueza
    ---> Os pobres acreditam: Investir é só pra quem já tem muito dinheiro.
    ---> Os ricos acreditam: Investir é como plantar: Começa pequeno e cresce com o tempo.
```
