# Os Segredos da Mente Milionária
T. Harv Eker


### Arquivo de Riqueza nº 1
```bash
  Pessoas de mentalidade pobre se colocam no papel de vítimas.

  Geralmente a culpa sempre é: Da família, namorada, amigos, economia, governo...
  Costumam culpar sempre os outros por sua situação, mas nunca a si mesmas.

  Essas pessoas acreditam que não têm controle sobre o que acontece na vida delas, e esperam que as coisas mudem sozinhas.

  Para criar riqueza, é necessário adotar uma mentalidade oposta.
  Isso significa:
  ---> Aceitar que você é o principal responsável por sua vida financeira.
  ---> Parar de culpar os outros.
  ---> Tomar ações para atingir suas metas.

  Os ricos se veem como criadores de sua realidade.
  Eles acreditam que suas decisões, ações e atitudes moldam o futuro.
  Eles buscam soluções, enfrentam desafios e assumem responsabilidade por seus resultados.

# Arquivo de Riqueza
  ---> Os pobres acreditam: A vida acontece comigo.
  ---> Os ricos acreditam: Eu crio minha própria vida.
```

### Arquivo de Riqueza nº 2
```bash
  Pessoas com mentalidade pobre se preocupam em economizar.
  Elas focam em como guardar dinheiro, e não em como fazê-lo crescer.
  Resultado? A pessoa rica aumenta suas chances de ganhar, enquanto a pessoa pobre nunca sai do lugar.

  Problema: Dinheiro parado nunca gera riqueza.
  Ricos enxergam dinheiro parado como perda, pois deixará de trabalhar para eles.
  Dinheiro é uma ferramenta para gerar mais dinheiro.

  ---> Renda Fixa = Perda Fixa

  Em vez de pensar: Quanto posso guardar este mês?
  Passe a pensar: Como posso multiplicar o que tenho?

  A chave é: Criar novas fontes de renda.
  Pense em maneiras de fazer o dinheiro crescer enquanto você dorme.

  O primeiro passo é sempre o mais difícil.

# Arquivo de Riqueza
---> Os pobres acreditam: Preciso proteger meu dinheiro.
---> Os ricos acreditam: Preciso multiplicar o que tenho.
```


### Arquivo de Riqueza nº 3
```bash
# Arquivo de Riqueza nº 3

  Pessoas ricas assumem o compromisso de serem ricas.
  Pessoas pobres apenas desejam riqueza.

  Pessoas de mentalidade pobre têm crenças limitantes que as impedem de alcançar riqueza, como:
  ---> "Eu posso perder tudo"
  ---> "Dá muito trabalho"
  ---> "Meus amigos/parentes vão dizer: Quem você pensa que é?"

  Querer somente não basta. 
  É preciso compromisso verdadeiro, e ir além.

  Nem sempre o "Querer" conduz a "Ter".
  Querer é um looping infinito que não leva a lugar nenhum.

  Basta observar a realidade: Bilhões de indivíduos querem ser ricos, mas relativamente poucos são.

  Comprometer-se significa: Dedicar-se incondicionalmente.
  Palavra-Chave: Incondicionalmente!

  É preciso estar disposto a fazer o que for necessário.

  Você está disposto a abrir mão e sacrificar seu tempo de lazer para alcançar a riqueza? 
  As pessoas ricas estão.

  "Serei rico ou morrerei tentando."

# Arquivo de Riqueza
---> Os pobres acreditam: Querer é o bastante.
---> Os ricos acreditam: Vou me dedicar incondicionalmente.
```
